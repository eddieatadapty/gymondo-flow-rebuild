# Gymondo Growth Audit

**Live → https://eddieatadapty.github.io/gymondo-flow-rebuild/**

Five ideas to turn more Gymondo users into subscribers, each built into a clickable version of Gymondo's own onboarding. Prepared by Adapty.

| # | Idea | Potential outcome |
| :-- | :-- | :-- |
| 01 | Ask while the plan is fresh, in their words | +10–20% CR to purchase |
| 02 | Show the plan the quiz promised | +5–15% CR to purchase |
| 03 | Let them start before you ask for anything | +5–10% CR to purchase · ARPU up to +17% |
| 04 | Put proof where they wait | +5–15% CR to purchase |
| 05 | Catch the people who close it | +5–10% CR from people who close it |

Every price, rating and feature comes from Gymondo's App Store listing, website or in-app screens. Impact ranges are Adapty’s expected effect from teardowns and A/B tests across 30,000+ subscription apps, not measured lift for Gymondo. They overlap, so they don’t add up.

Static single page, no build step: `python3 -m http.server`.
